
🧪 OSPF Lab — 3 Routers, 3 Switches, 6 PCs
1. Task
Goal: Configure OSPF so that all three networks can communicate with each other.
Networks:
LAN 1 → 192.168.1.0/24
LAN 2 → 192.168.2.0/24
LAN 3 → 192.168.3.0/24
Router Links:
R1 ↔ R2 → 192.168.10.0/24
R2 ↔ R3 → 192.168.20.0/24
R1 ↔ R3 → 192.168.30.0/24
Requirements:
Configure IP addresses on all routers.
Configure IP addresses and gateways on all PCs.
Configure OSPF on all three routers.
Use OSPF Area 0.
Advertise all connected networks through OSPF.
Verify OSPF neighbors.
Verify the routing table.
Test connectivity between PCs in all three networks.
